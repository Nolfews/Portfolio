# Hey, welcome to my portfolio 👋

> **Creating with imagination. Moving forward with determination.**

This repository contains the source code for my personal portfolio. It is designed to present my journey, my projects and the areas of development I am passionate about.

I am a developer in training who enjoys turning ideas into concrete projects. From web development and software to video game creation, I enjoy both imagining new experiences and understanding the technical systems that make them possible.

## 🎮 What I like to create

- **Video games:** RPGs, shooters, FPS and projects developed with Unreal Engine.
- **Software:** projects that help me explore software design and solve concrete problems.
- **Web development:** modern, accessible and enjoyable interfaces.

## 🛠️ Tech stack

This portfolio is built with:

- **Framework:** Next.js / React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Version control:** Git / GitHub
- **Hosting:** Vercel

## 🧠 Beyond the interface

I also enjoy exploring the more technical aspects of development: ECS architectures, packet transmission protocols, databases and system design.

For me, a project is more than what appears on screen. I like understanding what happens behind the scenes, considering possible solutions and finding the one that best fits the problem.
